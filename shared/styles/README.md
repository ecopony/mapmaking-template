# Style library

GIS symbology recipes, in words, so a layer treatment from one map can be repeated in the
next. GIS styling lives in the application and is invisible to this repo, so it's recorded
here. Managed by the `style` skill (`save "<Name>, <recipe>"` / `retrieve <name> style`).
One file per style; index below, alphabetical.

- [Elevation zones ramp](elevation-zones-ramp.md) — sequential green→tan fill for classified elevation bands, ~50% opacity over hillshade
